# Independent verification — spec r1 (Craft Shuffler / Imager / MS Matrix)

Performed 2026-10-29 by the verifier (analyst side), per step 5 of [docs/process.md](../process.md).
Only observed differences are reported here; no reference-side implementation detail is passed to the builder.

## Method
- Host: REAPER 7.83 (x64, Windows), unattended, offline render, 32-bit float, 48 kHz.
- Build under test: `feat/stereo-imager` @ f13d421, Release VST3 from the local MSVC build.
- Stimulus: user-generated exponential sine sweeps (10 Hz – 22.8 kHz), left-only and right-only, at −30/−12/−3 dBFS.
- 114 parameter configurations (each control swept individually, all toggles, combinations, near-neutral edge cases,
  and one "all controls moved" case). Controls were set by their **displayed values**, independent of the build's
  internal parameter mapping.

## Results
| Comparison | Configs | Worst | Median |
|---|---:|---:|---:|
| Build vs. approved spec r1 model | 114 | −144.5 dB re peak | −148.0 dB |
| Build vs. reference, shuffler inactive | 80 | −138.5 dB (77 configs); −45 … −52 dB (3 configs, see below) | |
| Build vs. reference, shuffler active, 48 kHz | 34 | differs by design (review decision: true sample rate instead of fixed 44.1 kHz design rate) | |

- The three outliers are Width values that fall exactly on a 0.01 quantisation half-step (e.g. 0.855): the build rounds
  away from zero, the reference rounds down. Spec §3 marks this as not compatibility-critical.
- All three plugins load in REAPER; parameter names, defaults and display formats match spec §3.

## Not yet verified
- Linux builds (CI only), CLAP hosting, 44.1/96 kHz host renders of the build, automation/smoothing in a host, GUI review.
