### A.0 Row ID legend
- `hpn_<r>` / `lpn_<r>`: HP / LP control at normalised position r (others neutral).
- `lf_<shape>_<Hz>_<gain>`, `hf_<shape>_<kHz>_<gain>`: LF/HF band, shape shelf|bell, frequency control (display), gain control (dB).
- `lmf_<kHz>_<Q>_<gain>`, `hmf_<kHz>_<Q>_<gain>`: mid bands, frequency control (display, kHz), Q control, gain control.
- `lff_/lmf_/hmf_/hff_<r>` (sweep tables): frequency control at normalised position r, gain +12 dB, Q 1.5 (mids), bell (LF/HF).
- `lmq_<r>`: LMF Q control at normalised position r, 1 kHz, +12 dB.
- `gl_/gh_/gm_*`: gain sweeps (LF 60 Hz bell/shelf, HF 8 kHz bell/shelf, LMF 1 kHz at Q 1.5 / 0.5).
